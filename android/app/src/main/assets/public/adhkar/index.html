الأذكار اليومية والسبحة الإلكترونية

أذكار الصباح والمساء الموثقة مع عدادات تفاعلية لإتمام الورد اليومي والسبحة الإلكترونية.

الرئيسية القرآن الكريم التفسير التلاوات المكتبة الأذكار مواقيت الصلاة

قراءة القرآن الكريم ومصحف المدينة

تصفح صفحات مصحف المدينة النبوية بالرسم العثماني الواضح مع أحكام التجويد وإمكانية القراءة دون اتصال بالإنترنت.

التفسير الميسر وتفسير السعدي

تأمل معاني الآيات بسهولة عبر التفسير الميسر وتفسير الشيخ السعدي مع تظليل الآيات وإضافة الملاحظات الشخصية.

الاستماع إلى التلاوات القرآنية

استمع إلى تلاوات القرآن الكريم بأصوات مئات القراء بمختلف الروايات مع الإذاعات القرآنية المباشرة والتحميل للاستماع دون إنترنت.

حفظ القرآن وخطة الختمة

نظم وردك اليومي عبر خطة الختمة المخصصة وتابع حفظ القرآن الكريم بنظام التكرار المتباعد والمراجعة الذكية.

الأذكار اليومية والسبحة

حصن يومك بأذكار الصباح والمساء مع عدادات تفاعلية والسبحة الإلكترونية لحفظ التسبيحات اليومية.

مواقيت الصلاة واتجاه القبلة

احصل على مواقيت الصلاة الدقيقة حسب موقعك الجغرافي مع بوصلة القبلة الحية ولوحة إشعارات الصلاة.
